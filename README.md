# DSM-4 MC Constraint Board

Single-file web app for tracking Mechanical Completion on DSM4 (Project Aura).

**This repository contains code only.** No project data is stored here — no systems,
no dates, no punch counts, no names. Everything the board displays lives in an
access-controlled Firestore database and is readable only by signed-in users on an
explicit email allowlist, enforced by database security rules rather than by the page.

Live: https://bdiaz8448-gif.github.io/DSM-4-MCC-Tracking/

Access is restricted to authorized project members.
